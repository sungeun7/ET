# 에메랄드 택틱스

파이어 엠블렘 / 택틱스 스타일의 브라우저 턴제 RPG입니다.
Rhapsody「Emerald Sword」의 서사 모티프(전설의 검 탐구 · 암흑과의 결전)를 오리지널로 각색했습니다. 원곡 가사는 포함하지 않습니다.

## 실행 방법

로컬에서 ES 모듈을 쓰려면 정적 서버가 필요합니다.

```bash
node server.js
```

브라우저에서 `http://localhost:5500` 을 여세요.

## 조작

- **좌클릭**: 유닛 선택 / 이동 / 공격
- **우클릭**: 선택 취소 (이동 전 원위치)
- **같은 유닛 재클릭 / 대기**: 공격할 적이 없으면 행동 종료
- **턴 종료**: 남은 아군이 있어도 적 페이즈로 넘김

## 목표

적 유닛을 모두 격파하면 다음 스테이지로 진행합니다. 총 50스테이지 · 5막 구성이며, 5의 배수마다 관문 보스가 등장합니다.
아군이 전멸하면 해당 스테이지를 다시 도전할 수 있습니다.
